## Rule-Based Chatbot | Python
This project is a simple rule-based chatbot developed using Python. It uses if-else logic,lists, dictionaries and loops to respond to predefined user inputs. It handles greetings, common queries and exit commands.

Key concepts used:

- Rule-based decision-making using conditional statements.
- Lists and dictionaries for storing keywords and predefined responses.
- Loops for continuous user interaction.
- String handling using `lower()` and `strip()`.
- Keyword matching and input validation.
